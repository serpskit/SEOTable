A lightweight, SEO-optimized table plugin for WordPress. Create professional, fully responsive comparison tables with color-coded badges, customizable headers, hover effects, and mobile-friendly layouts — perfect for product reviews, feature comparisons, and data-driven content that ranks.

== Description ==

SERPsKit SEOTable lets you build beautiful, accessible tables directly inside the WordPress Block Editor. Designed for bloggers, affiliate marketers, and content creators who need tables that look great, load fast, and help content rank.

**Key Features:**

* Gutenberg Block — create tables right inside the post/page editor
* Color-coded badges — green, blue, amber, red, gray, and brand tag badges
* Row hover effects — matching professional comparison table UX
* Convert WordPress default tables — transform core/table blocks into SEOTables
* Fully responsive — horizontal scroll on mobile, clean on desktop
* Dashboard settings — customize heading colors, border styles, font sizes, row colors, and more with live preview
* Lightweight — minimal CSS/JS with no jQuery on frontend
* SEO-friendly — clean semantic HTML table markup

== Installation ==

1. Upload the `serpskit-seotable` folder to `/wp-content/plugins/`
2. Activate the plugin through the Plugins menu
3. Go to SEOTable in the admin sidebar to configure settings
4. In any post/page, add the "SEOTable" block from the inserter

== Frequently Asked Questions ==

= Can I convert my existing WordPress tables? =
Yes. Select any core Table block, click the block toolbar, and choose "Transform to → SEOTable".

= Is it mobile responsive? =
Yes. Tables scroll horizontally on small screens with smooth touch scrolling.
